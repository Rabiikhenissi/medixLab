1.2 Création d'une facture

Depuis le centre (manuelle)

  • Route : POST /center/billing → BillingController@store
  • L'utilisateur sélectionne une demande d'examen et saisit les articles avec leurs prix
  • Pour chaque article avec cnam_code :
1. Récupérer CnamNomenclature via code_cnam
2. valeur_b = celle saisie OU celle de la nomenclature
3. taux = cnam_affiliation.rate.taux (catégorie du patient)
4. cnam_coverage = valeur_b × quantity × (taux / 100)
5. cnam_amount = somme(cnam_coverage)
6. patient_amount = max(0, total_amount - cnam_amount)

Automatique (à la complétion des résultats)

  • Déclenché dans ExamRequestService::checkCompletion() quand tous les résultats sont saisis
  • Vérifie qu'aucune facture n'existe déjà pour cette exam_request_id
  • Utilise les prix de AvailableExam pour le laboratoire concerné
  • Applique le même calcul CNAM
  • Statut initial : pending

1.3 Paiements — Workflow complet

Patient soumet → Pending → Labo confirme → Confirmed
  1. Patient soumet → Payment.status = 'pending', la facture n'est pas modifiée
  2. Notification envoyée à tout le staff du laboratoire : "Nouveau paiement en attente"
  3. Staff du labo voit le paiement "En attente" sur la page de la facture + bouton "Confirmer le paiement"
  4. Confirmation → Payment.status = 'confirmed', confirmed_at = now()
  5. Mise à jour facture : paid_amount recalculé, status mis à jour (paid / partially_paid)
  6. Notification patient : "Votre paiement a été confirmé par le laboratoire"

1.4 Balance (solde restant)

// Invoice.php — Attention : utilise patient_amount, PAS total_amount !
public function getBalanceAttribute()
{
    return $this->patient_amount - $this->paid_amount;
}

La balance ne tient pas compte de cnam_amount car la part CNAM n'est pas due par le patient.

2.3 Calcul détaillé

Pour chaque item avec un code CNAM :

1. Récupérer la nomenclature CNAM via code_cnam
2. Déterminer valeur_b :
   - Priorité : valeur_b saisie manuellement > valeur_b de la nomenclature
3. Récupérer le taux patient :
   - Via cnam_affiliation.rate.taux (100% pour Assuré social)
4. Calculer la couverture CNAM :
   cnam_coverage = valeur_b × quantity × (taux_patient / 100)

5. cnam_amount = somme de tous les cnam_coverage
6. patient_amount = max(0, total_amount - cnam_amount)

2.4 Affichage côté patient

Sur la page détail de la facture, un tableau "Prise en charge CNAM" montre pour chaque item :

  • Code CNAM
  • Valeur B
  • Taux (catégorie du patient)
  • Couverture CNAM

Le résumé affiche : Total → Part CNAM → Net à payer

3.2 Génération des codes-barres

Format : SAMP-{laboId}-{6 chiffres séquentiels}
Exemple : SAMP-21-000001

  • Basé sur le dernier ID pour ce laboratoire
  • Affiché avec JsBarcode (code128) sur les pages d'impression
  • Bibliothèque chargée depuis CDN : https://cdn.jsdelivr.net/npm/jsbarcode@3.11.6

5. Points clés à retenir

  1. La Valeur B est le montant de base fixé par la CNAM pour chaque acte — pas le prix du laboratoire
  2. Le taux patient dépend de sa catégorie (Assuré social = 100%, Conjoint = 50%, Enfant = 25%)
  3. La couverture CNAM = Valeur B × Quantité × (Taux patient / 100)
  4. Le patient ne paie que total_amount − cnam_amount, jamais plus
  5. Les paiements passent par un workflow pending → confirmed : le patient soumet, le labo confirme
  6. Les codes-barres utilisent le format SAMP-{laboId}-{seq} avec JsBarcode (code128)
  7. La facture est créée automatiquement quand tous les résultats d'une demande sont saisis
  8. La balance utilise patient_amount − paid_amount (pas total_amount)
  9. Pas de passerelle de paiement réelle : le "Paiement en ligne" est confirmé manuellement par le labo
  10. Toute action importante génère une notification (patient, docteur, staff du labo)
